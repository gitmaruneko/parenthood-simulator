# 家庭生活回顧（Issue #12）

完成第 12 個 AgeStage 後直接開啟回顧；首頁「重看家庭紀錄」也開啟同一份回顧。
讀取回顧不推進故事、不消耗 PRNG，也不寫入存檔。

## 資料與敘事

`createFamilyReview(GameState, ContentPack)` 是引擎公開邊界。依年齡順序建立
12 個時間線區段，每段收錄該 AgeStage 的全部 history，不以 Turn 數量推算階段。
回顧保留人物反應、實際選擇、支持、修復與 planning 敘事；呈現家庭條件、
敘事總覽、開場／末段資源及末段 planningLoad。資源描述處境，不合成分數。

預設關鍵時刻取已確認選擇中的第一段、中段與最後一段。玩家可改選三段；
`selectReviewMoments` 驗證三個不同且有已確認選擇的 history ID，寫入既有 review 契約。
還原後保留選取，其他摘要從實際歷史重建，不信任保存的分享文字。

六個柔性主題依實際選擇與敘事證據取至多兩個。第一個優先描述休息選擇、
雙薪工作安排、衝突後修復、可用支持，無符合項目時使用「一起慢慢長大」。
第二個描述人物由批評轉為理解的變化，否則使用連結記憶、修復或支持，且不重複。
標籤不鎖定事件路線，也不代表道德或育兒評量：

| 主題 | 使用的故事證據 |
| --- | --- |
| 一起慢慢長大 | connection 關係記憶；亦作無明確主題時的描述 |
| 忙碌的雙薪日常 | 雙薪處境中，實際走過工作場景並作出選擇 |
| 有人同行的旅程 | support 故事片段 |
| 學著照顧自己 | 實際選擇回補能量，或在休息場景說出需求、協調時段 |
| 一邊衝突一邊修復 | 衝突記憶與 repair 故事片段；亦可描述後續修復片刻 |
| 意想不到的成長 | 同一人物早先批評／衝突，後來出現理解反應 |

## 重玩與分享

新生成的家庭保存可選 `replayOrigin`：開場資源、傾向、PRNG 狀態與人物目錄。
這個向後相容的欄位沿用 save schema v3；同種子重玩從該開場開始，清除故事歷史、
負擔及選取，重新採用預設生活方向。家庭曾經 reroll 也能保留實際開場。
還原人物目錄也使用此快照，避免重建成不同的人物參與數值。
舊存檔沒有開場快照時，只能按種子重建預設開場，無法還原當時的測驗／reroll 細節。

相同種子重玩與認識新家庭皆走既有替換確認、保留原始資料及衝突檢查。
取消或停在揭示頁不改寫完成紀錄；「開始這個家庭」才保留原檔並替換。

分享預覽使用固定文字與受控主題名稱，不插入 preferredAddress、history、
人物資料、健康資訊、資源、seed 或 PRNG。複製失敗時提供手動複製提示，無自動發佈。

## 驗證

測試邊界沿用 ticket：Core Event Engine Public Boundary、Save / Restore Boundary。
涵蓋 12 階段與多 Turn、三段選取及無效 ID、穩定生成、六個標籤、分享資料隔離、
開場快照／reroll 重玩、Session 儲存還原與替換確認。
桌面與手機 Playwright 完整流程覆蓋完成、重開、編輯、分享預覽、取消與確認重玩。
