## 本機使用

需要 Node.js 22.12+ 或 24。執行 `npm install`、`npm run dev`，開啟終端機顯示的本機網址。
Windows PowerShell 若封鎖 `npm.ps1`，請使用相同指令的 `npm.cmd`。
`npm run build` 同時編譯原有 TypeScript 模組與瀏覽器應用，網頁輸出位於 `dist/web`；
`npm run preview` 可檢視正式建置。

## 邊界

- `src/ui/player-session.ts` 協調家庭生成、引擎與存檔公開介面；React 只訂閱呈現快照並提交命令。
- 引擎 `getPlayerView` 提供可用選項、下一個生命週期命令、AgeStage／Turn 與完成狀態，讀取不改變 PRNG。
- Persistence `inspectPlayerSave` 分類首頁狀態，包括損壞、不相容內容／版本、遷移及存取失敗。元件不解析原始存檔。
- 開場與 Reroll 先留在記憶體；「開始這個家庭」才提交存檔。新故事同意綁定確切原始資料，提交前再查一次。
- 既有資料由 `replaceAfterConfirmation`／`migrate` 先保留，再替換；保留失敗即停止。沒有永久收藏、雲端同步、自動修復或備份還原入口。
- 每次選擇與自動節點經 `transitionAndSave` 保存。失敗後保留記憶體中的結果；空間／存取錯誤可重試儲存，不重抽事件。衝突要求重新讀取，禁止以重試覆寫另一分頁的新故事。
- 「繼續故事」只結束目前段落的閱讀；下一個引擎命令使用不同按鈕。分頁、預覽、資訊抽屜與閱讀均不改變 GameState。

## 畫面與範圍

2026-10-24：開場前兩題採假設情境，各六種候選、預設四項並可展開。家庭成員改為角色稱呼、家庭關係、孩子目前年齡及最新人物反應；成人詳情可展開家庭照顧／工作脈絡。未生成的角色不顯示，姓名、成人年齡、個人職業與孩子特質缺口見[影響分析](implementation/OPENING-FAMILY-IMPACT.md)。

續作已對照四張參考圖：成員區塊增加家庭照顧／工作短摘要，近況標示原始故事時間，詳情顯示該角色最近三筆已有關係記憶；無近況不補敘事，相同稱呼與關係不重複列出。這些是唯讀呈現欄位，不修改存檔或生成器契約。

首頁包含五個敘事區塊、四幅原創 SVG 家庭草圖及依存檔分類的操作列。
操作列量測實際高度、保留頁尾空間，短視窗或文字放大時改為文流；對話框採原生 `dialog` 的模態焦點與背景隔離。
遊玩在 1024px 以上為三欄，768–1023px 為故事加資訊抽屜，767px 以下為生活／家庭／紀錄／心事四分頁。
家庭資源不以道德分數呈現；父母心事直接使用內容提供的 planning／support／repair 敘事。
家庭生活紀錄每個已確認事件僅顯示一筆精簡摘要（孩子年齡與天數、事件名稱與選擇），
不再把安排或人物反應各列一筆，也不重複事件正文；窄螢幕可自然換行。
這是呈現調整，原始歷史與存檔資料完整保留。
生活故事與家庭生活紀錄皆以最新在上呈現；閱讀完畢後直接提供下一步按鈕，不顯示 Turn 結束說明。
紀錄時間由引擎唯讀呈現介面提供，例如「2 個月 1 天」「2 個月 2 天」。
每個階段以自身月齡為基準，同 Turn 的事件共用一天；下一 Turn 顯示下一天。
這是敘事時間標籤，不改變引擎的 Turn／排程或存檔格式；頁首仍保留獨立的 AgeStage 與 Turn 進度。

完成 12 階段後直接呈現[家庭生活回顧](FAMILY_REVIEW.md)（#12），首頁也能重開。
回顧包含十二階段、三個可調整且保存的關鍵時刻、支持與修復、隱形負擔與資源脈絡、
一至兩個柔性主題、安全分享文字及相同種子／新家庭入口。沒有加入帳號系統。

## 驗證

- `npm test`：原有領域測試，加上引擎唯讀快照、實際 Session／Save 整合，以及固定呈現快照與命令 spy 的元件測試。
- `npm run typecheck`、`npm run build`：型別與正式建置。
- 首次執行 `npx playwright install chromium`，再執行 `npm run test:e2e`：桌面與手機 Chromium 流程。CI 原有 tests／typecheck／build 保持可用；Playwright 需另安裝瀏覽器並執行。
- 瀏覽器案例包括首頁預覽、完成／跳過測驗、Reroll、選擇／反應／AUTO_ADVANCE、手機分頁、重新整理還原、重開取消／確認、損壞資料保留、遷移成功／失敗、儲存拒絕、完整 12 階段與唯讀紀錄。
- 版面案例包含 320／390／768／1024／1440px、200% 根文字大小及縮窄重排；視覺截圖輸出在忽略追蹤的 `test-results/`。

尚需人工驗收：桌面／手機螢幕閱讀器、實機 Safe Area／虛擬鍵盤、瀏覽器原生 400% 縮放、完整 WCAG 2.2 AA 審核，以及 10–15 分鐘體驗時間。
自動化與 Chromium 模擬結果不等同這些人工驗收已通過。
